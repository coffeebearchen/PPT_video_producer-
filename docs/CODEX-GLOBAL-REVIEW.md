## 3. 这个软件的目标（先理解，再评价）

```text
一个本地内容平台「固定地址」：
  输入选题/文案 → 自动生成竖屏短视频（讲解/图解类）
  → 可预览、可修改、可发布到视频号（手动）和公众号（草稿）。

核心诉求：
  - 大量内容自动生成，人只在关键处参与
  - 画面要像“手绘讲解视频”，有信息密度、有动效、有设计感
  - 三个讲解风格：简洁 / 严谨工业 / 活泼动感
  - 两个引擎都要保留，但人要容易操作、不混淆
  - 合规：不自动发布，人最后确认
```

## 4. 请从这些角度全局审视

```text
1. 架构一致性：两套引擎、两套数据模型、两套页面，哪里会让人困惑？

7. 安全合规：凭据、AI 标识、素材许可、自动发布边界。
8. 用户体验：菜单、命名、一页全流程，还有哪里难用？
```
