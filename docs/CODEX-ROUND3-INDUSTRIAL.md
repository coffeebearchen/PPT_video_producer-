## 3. 目标风格：严谨工业风

重点提取并实现：

```text
1. 背景色：深色/工业灰，低饱和
2. 字体层级：小标签 / 大标题 / 数据 / 来源说明，层级清晰
3. 对齐：网格感、左对齐或严格居中
4. 间距：紧凑但有呼吸，不拥挤
5. 细分隔线：细线分割、卡片边框
6. 图解关系：流程/对比/数据图表清晰
7. 数据强调：关键数字放大、变色、标注
8. 来源说明：数据/结论的出处小字说明
```
