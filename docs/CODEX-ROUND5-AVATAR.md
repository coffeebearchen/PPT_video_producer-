# 给 Codex 的指令：数字人口播（可选，简单版先做）

> 这是可选项，不是每条视频都要。
> 本轮先做“简单版”：头像 + 嘴部动画，用本地实现，不接外部付费服务。

---

## 1. 目标

```text
生成视频时，可选加一个“数字人口播”：
  一个头像在讲，嘴跟着声音动（口型跟随）。
```

## 2. 需求

```text
1. 可选开关：style 或 DSL 字段控制，例如 avatar: true
2. 输入：
   - 头像图（内置默认卡通头像，或用户上传）
   - 你的声音（已有 TTS / 导入配音）
3. 嘴部动画：根据音频能量驱动张嘴（本地计算，不接外部）
4. 位置：右下角小窗 或 居中，不遮主内容
5. 默认关闭；每条视频可选
```

## 3. 简单版实现（本轮）

```text
- 静态头像（内置/上传）
- 嘴部：根据当前音频能量做“张嘴/闭嘴”动画
- 简单呼吸/轻微点头，克制不夸张
- 这是“模拟口型”，不是逐字精确；明确标注，不宣称精确口型
```

## 4. 精确版（以后，本轮不做）

```text
接数字人服务（火山/硅基/腾讯智影）做真实口型。
本轮只留好接口，不接付费服务。
```

## 5. 硬性约束

```text
不复制参考人物
不用 AI 生图（头像用内置卡通/用户上传）
头像不遮字幕、图表、80% 安全区主内容
可开关，默认关
```

## 6. 验收

```text
用一段已有配音 + 内置头像，
出一条 10–15 秒“数字人口播”样片：
  嘴跟随声音、位置不挡内容
抽 6–8 帧 contact-sheet.png 给我看
```

## 7. 交付

```text
1. 新增哪些组件（avatar / mouth 动画）
2. DSL 如何开启（字段名）
3. 样片本地路径
4. 测试结果 + 未验证项
```
