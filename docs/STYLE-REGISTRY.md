# 讲解风格注册表（三种）

平台视频生成时的可选讲解风格。风格字段：`style`，取值三个。

```text
style = clean       简洁风格
style = industrial  严谨工业风
style = dynamic     活泼动感风
```

---

## 1. clean · 简洁风格

```text
定位：讲清楚一件事，不打扰。
画面：元素少、留白多、克制。
动效：单个主要动效，干净利落。
装饰：少量手绘插画 / 动感插画点缀，不喧宾夺主。
配色：柔和，主色 1 个 + 中性色。
```

## 2. industrial · 严谨工业风

```text
定位：论证、干货、数据、来源可信。
画面：深色/工业灰背景，细分隔线，网格感。
字体：层级分明（小标签 / 标题 / 数据 / 来源）。
数据：强调数值、图表、来源说明。
动效：克制、精准（柱状生长、节点点亮、进度推进）。
```

## 3. dynamic · 活泼动感风

```text
定位：吸睛、引流、有节奏。
画面：流动线条、动感轨迹、强烈对比。
动效：更丰富、切换有节奏、高亮明显。
装饰：流动线 / 粒子 / 扫光（有控制，不杂乱）。
```

---

## 平台接口约定（DSH 负责接）

```text
1. 工作台新增「讲解风格」下拉：
   clean / industrial / dynamic

2. 存到 video_tasks.style 字段

3. 生成 DSL 时，style 映射到：
   palette（配色）
   density（密度）
   motion（动效强度）
   decor（装饰）
```

Codex 负责在渲染层实现三种风格；DSH 负责把 `style` 字段接进中台和 DSL 生成器。
