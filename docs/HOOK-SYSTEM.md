# 钩子系统 v1

目的：让观众在前 2 秒停下来，并且看完能得到一个明确的“代价 / 判断 / 去处”。

钩子不是标题党。  
钩子必须在这条视频里被兑现，否则流量会反噬。

---

# 一、钩子的五种触发

```text
钱      账单、成本、浪费
损失    事故、翻车、隐私
身份    我妈、老板、实习生、普通人
冲突    打假、反常识、旧说法失效
可验证  实验、对比、同一问题三遍
```

七个结构，本质是这五种的组合。

---

# 二、七个结构

## ① 账单式

**触发**：钱

**适合**：Token、上下文窗口、API、算力、模型大小

**2 秒句**

```text
你问一句收 3 分，贴 500 页收 3 块。
```

**promise**

```text
它不是按难度收费，是按你塞进去的长度收费。
```

**兑现**

```text
一张账单对比
长上下文 vs 分段提问
一句结论：先问“要哪几段”
```

**结尾扣子**

```text
下一条：为什么读了 500 页，还是记不住第 3 页。
```

**视觉**

```text
数字从 0.03 滚到 3.00
“按长度”三个字放大
高亮落在“长度”
```

---

## ② 打假式

**触发**：冲突

**适合**：参数规模、AGI、跑分、榜单

**2 秒句**

```text
“参数越大越聪明”，这句话已经过期了。
```

**promise**

```text
一个 70 亿的专用模型，能打赢千亿通用模型。
```

**兑现**

```text
左边旧结论变暗
右边新结论变亮
一个具体任务对比
一句边界：不是所有任务都成立
```

**结尾扣子**

```text
下一条：为什么小模型便宜 20 倍，还更快。
```

**视觉**

```text
1000 亿 / 70 亿 两个色块对撞
旧结论打叉，新结论打勾
```

---

## ③ 事故式

**触发**：损失

**适合**：幻觉、越狱、隐私、数据泄露

**2 秒句**

```text
律师用 AI 写诉状，6 个判例全是编的。
```

**promise**

```text
它不是想骗人，它只是被训练成“必须给一个答案”。
```

**兑现**

```text
6 张判例卡依次出现
全部红叉
一句结论：它默认不会说“我不知道”
```

**结尾扣子**

```text
下一条：怎么一句话逼它老实交代。
```

**视觉**

```text
卡片出现 → 红叉 → 碎裂
关键词“必须给答案”高亮
```

---

## ④ 实验式

**触发**：可验证

**适合**：温度、随机性、提示词、参数

**2 秒句**

```text
同一个问题问三遍，它都叫“山海”。
```

**promise**

```text
把温度从 0.2 调到 1.2，三个名字完全不同。
```

**兑现**

```text
三个同名卡片并排
滑块向右
卡片文字变化
一句结论：写合同调低，起名字调高
```

**结尾扣子**

```text
下一条：为什么调太高，它开始胡说。
```

**视觉**

```text
同名卡片 → 滑块 → 文字跳动
关键词“敢不敢乱来”高亮
```

---

## ⑤ 拟人式

**触发**：身份

**适合**：Agent、RAG、微调、记忆

**2 秒句**

```text
你把 AI 当搜索引擎，它就是个词典。
```

**promise**

```text
你把它当实习生，它会查资料、开表格、发邮件。
```

**兑现**

```text
一个问题 vs 一个任务
问题：答完就停
任务：自己找下一步
一句结论：差别不在模型，在交付
```

**结尾扣子**

```text
下一条：为什么这个实习生会偷偷把数据发出去。
```

**视觉**

```text
搜索框 → 任务卡 → 三条支线：查 / 做 / 发
```

---

## ⑥ 翻译官式

**触发**：揭穿

**适合**：对齐、涌现、原生、赋能、Agentic

**2 秒句**

```text
发布会上说“我们完成了对齐”。
```

**promise**

```text
翻译一下：教会它别说脏话、别教人做炸弹、别顶嘴。
```

**兑现**

```text
黑话卡翻面
背面是白话
一句结论：最难懂的话，常常是讲的人也没完全懂
```

**结尾扣子**

```text
下一条：三秒看穿一场 AI 发布会。
```

**视觉**

```text
“对齐”大字 → 翻牌 → 背面白话
```

---

## ⑦ 门外汉式

**触发**：人格

**适合**：任何词，尤其系列开篇/收尾

**2 秒句**

```text
我妈问我：AI 是不是把全世界的书都背下来了？
```

**promise**

```text
不是。它更像把全世界的话都听过，然后学会了接话。
```

**兑现**

```text
一本大书合上
变成一条对话气泡链
一句结论：它能写得像人，也能错得像人
```

**结尾扣子**

```text
下一条：为什么它答得越顺，你越该警惕。
```

**视觉**

```text
书 → 气泡链 → 越来越长
```

# 三、2 秒规则

在我们的视频里，前 2 秒只有两行：

```text
cover.lead   钩子句，<= 20 字
cover.punch  承诺/反转，<= 12 字
```

不要：

```text
第一句是“今天我们来聊聊……”
第一句是定义
第一句是背景
```

要：

```text
第一句就有钱 / 损失 / 身份 / 冲突 / 结果
```

---

# 四、页面映射

```text
P1 封面   钩子 + 承诺
P2 背景   这个代价发生在什么场景
P3 对照   旧认知 vs 新认知
P4 证据   具体案例 / 实验 / 账单
P5 金句   一句判断
P6 结尾   下一条 + 一个动作
```

4 页版：

```text
封面 → 背景 → 对照 → 结尾
```

5 页版加证据，6 页版加反例。

---

# 五、30 期轮换

不要连续用同一种。

建议顺序：

```text
01 账单
02 拟人
03 事故
04 打假
05 门外汉
06 实验
07 翻译官
08 账单
09 事故
10 拟人
...
```

同一词可以换结构重做：

```text
Token：账单式
Token：门外汉式
Token：实验式
```

三条不是重复，是三种入口。

# 七、兑现规则

每个钩子必须配一个“兑现物”：

```text
账单式   → 一张账单 / 对比表
打假式   → 一个真实任务 / 数据
事故式   → 一个真实案例 / 来源
实验式   → 一次真实实验
拟人式   → 一个任务流程
翻译官式 → 一张黑话卡
门外汉式 → 一个生活类比
```

没有兑现物，就不要用这个钩子。

---

# 八、反作弊

```text
不编判例
不编价格
不编跑分
不编用户案例
不把“可能”写成“一定”
```

示例里的数字是示范。  
真实视频必须能拿出处，否则会伤品牌。

---

# 九、一条视频的完整骨架

```text
0–2s    钩子
2–6s    代价 / 冲突
6–14s   证据 / 实验 / 账单
14–20s  一句判断
20–24s  下一条
最后    一个动作
```

动作只留一个：

```text
评论区打「账单」
或
关注，下一条
```

不要同时放两个。

# 十、和现有流水线的关系

不需要重做模板。

只需要给 spec 增加：

```json
{
  "hook_type": "bill | debunk | accident | experiment | persona | translator | outsider",
  "hook_trigger": "money | loss | identity | conflict | proof",
  "hook_promise": "一句承诺",
  "next_teaser": "下一条讲什么",
  "cta_keyword": "账单"
}
```

现有 `page1.cover.lead / punch` 直接承载前 2 秒。

动画只做第二层钩子：

```text
账单：数字滚动
打假：色块对撞
事故：卡片碎裂
实验：滑块变化
拟人：搜索框变任务卡
翻译官：翻牌
门外汉：书变气泡
```

# 十一、v1 外部钩子库落地

这份 7 结构 + 30 开头模板 + 自检清单，定为 **Hook Library v1**。

它不是视频模板库，是**脚本结构库**。

直接套现有流水线，会出现一个问题：

```text
换了开头
但画面还是同一种
```

所以需要把 7 个结构各自拆成一个“可渲染场景”。

## 1. 数据字段

```json
{
  "hook_type": "bill | debunk | incident | experiment | persona | translator | outsider",
  "hook_trigger": "money | loss | identity | conflict | proof",
  "hook_template_id": "bill-01",
  "hook_promise": "一句承诺",
  "next_teaser": "下一条讲什么",
  "cta_keyword": "账单",
  "proof": {
    "kind": "source | experiment | calculation",
    "ref": ""
  }
}
```

## 2. 页面映射

```text
P1  钩子
P2  代价 / 冲突 / 场景
P3  证据 / 对比 / 实验
P4  判断
P5  下一条 + 一个动作
```

4 页版：

```text
P1 钩子 → P2 代价 → P3 判断 → P4 下一条
```

5 页版：

```text
P1 钩子 → P2 代价 → P3 证据 → P4 判断 → P5 下一条
```

6 页版加反例。

## 3. 七个可渲染场景

```text
bill        数字滚动 / 价格对比
debunk      旧结论压暗 / 新结论点亮 / 对撞
incident    卡片出现 / 红叉 / 碎裂
experiment  并排结果 / 滑块 / 文字变化
persona     搜索框变任务卡 / 三条支线
translator  黑话翻牌 / 背面白话
outsider    书合上 / 气泡链
```

这些必须是**新的场景组件**，不是换文案。

## 4. 2 秒与 100 字约束

```text
cover.lead   <= 20 字
cover.punch  <= 12 字
全文         <= 100 字
```

超过就改写，不缩字号。

钩子必须在前 2 秒被看见，动画只是第二层。

## 5. 一个动作

一条只留一个：

```text
评论区打关键词
或
关注，下一条
```

不能同时放。

## 6. 事实闸门

```text
事故式：必须有来源
打假式：必须有对比
实验式：必须真跑
账单式：必须算得出来
```

没有 proof，不用这个钩子。

## 7. 测试顺序

```text
先做 3 条：
Token  账单式
幻觉   事故式
Agent  拟人式
```

看：

```text
前 2 秒留存
完播
评论关键词
关注
```

不要一次做 30 条。

## 8. 系列轮换

```text
7 种各用一次
第 8 期把数据最好的提前
绝不连续同一种
```

同一词可以换结构重做，但要有新证据，不是换标题。
