# 蚁小二接入前补充清单

日期：2026-11-08  
目的：在写代码前把契约、边界和测试条件定死，避免返工。

---

## 1. 定位

必须先定：

```text
自用工具
还是
给团队 / 客户的产品
```

影响：

```text
权限
审计
多租户
费用
发布责任
```

当前建议：

```text
先按自用 / 小团队做
不先做权限系统
```

---

## 2. 首发平台范围

不建议一次接四个平台。

建议第一轮：

```text
一个平台
一个测试账号
一条内容
```

候选：

```text
小红书 imageText
或
公众号 article
```

原因：

```text
字段少
容易验证
失败原因清楚
```

视频号 / 抖音放第二轮。

---

## 3. 确认发布点

需要定死：

```text
我们的软件点“通过”
蚁小二只执行
平台再审
```

不再在蚁小二重复人工确认。

除非平台强制。

---

## 4. Dry-run 策略

第一轮必须：

```text
只 dry-run
不正式发
```

通过后再开一条真实发布。

---

## 5. AI 标识策略

四平台现状：

```text
抖音：statement=3 可声明 AI
小红书：表单无独立字段
视频号：表单无独立字段
公众号：文章表单无独立字段
```

需要决定：

```text
没有字段的平台
是否要求人工在平台后台声明
还是暂不发布
```

不能假装已经声明。

---

## 6. 平台变体规格

先定四个 profile：

```text
公众号 article
  长文 HTML + 配图

视频号 video
  1080×1920 / 20–28s

小红书 imageText
  1080×1440 图文卡片

抖音 video
  1080×1920 / 更短钩子
```

不能四个平台共用同一个视频文件。

---

## 7. 发布时间策略

建议：

```text
固定窗口 + 随机抖动
```

```text
09:00–22:00
每条偏移 15–90 分钟
同账号两条间隔 ≥ 2 小时
每天上限可配
```

不做：

```text
完全随机
凌晨发
同一分钟批量发
```

---

## 8. 失败处理

必须定义状态：

```text
draft
approved
queued
uploading
task_created
published
failed
blocked
```

失败原因分类：

```text
账号失效
字段缺失
schema 不通过
平台审核拒绝
素材上传失败
任务超时
```

失败后：

```text
进人工队列
可重试
可换 provider
不静默失败
```

---

## 9. 真实 Schema 快照

现在四张映射表来自文档。

必须补：

```text
yxer schema fields 小红书 imageText
yxer schema fields 视频号 video
yxer schema fields 微信公众号 article
yxer schema fields 抖音 video
```

保存为：

```text
docs/schemas/yixiaoer-<platform>-<type>-<date>.json
```

没有快照，不要写死字段。

---

## 10. 账号与 API 条件

需要准备：

```text
蚁小二企业 API Key
正式 base URL
一个已授权测试账号
平台账号列表
IP / 登录环境
```

公众号还需要：

```text
服务号 / 订阅号权限确认
AppID / Secret
IP 白名单
```

---

## 11. 数据隔离

蚁小二分支必须使用：

```text
独立 data 目录
或独立工作副本
```

不能和当前生产库共用。

---

## 12. 冻结条件

在开始蚁小二开发前：

```text
提交当前账号组改动
打 tag v2.3.0
备份 studio.db
生成 release zip
```

---

## 13. 验收标准

```text
content_id 贯穿
四个变体独立
schema 校验通过
dry-run 通过
真实发布一条
platform_ref 回写
失败有原因
主库不被污染
```

---

## 14. 暂不做

```text
自动通过
批量相似内容
四平台同时首发
权限系统
多租户
复杂 BI
```

---

## 15. 现在最需要确认的 5 件事

```text
1. 自用还是产品
2. 第一轮先接哪个平台
3. 是否只 dry-run 起步
4. 无 AI 字段的平台怎么声明
5. 蚁小二账号和 API Key 是否已就绪
```
