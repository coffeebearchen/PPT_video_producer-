## 6. 要解决的核心问题（按优先级）

```text
P0 视觉密度与动效：
   现在视频像 PPT，一屏元素太少、太静态。
   目标：每屏 8–20 个视觉元素，每 2–4 秒一次变化
   （点亮/生长/高亮/镜头推近），至少 7 种元素类型。

P1 智能排版：
   元素现在固定在几个角落，不能按画面留白避让。
   每个组件要声明“可用区域/避让区”，
   AI 根据画面决定元素放哪、不压文字。

P2 标注层 + 质感层进主渲染：
   手绘圈/下划线/高亮/箭头/编号气泡，
   颗粒/粒子/扫光/暗角/斜纹，
   现在只在画廊预览，要搬进 Video.tsx / SceneDecor，
   按模板 density 开关。

P3 封面自动生成：
   每条视频自动出 cover.png（1080×1920）
   和 cover_3x4.png（1080×1440），与正片同字体同配色。

P4 语音 ↔ 画面精准对齐：
   现在时间戳是按字数估算的桩。
   目标：按真实配音时长逐句对齐，
   每句话对应哪个画面/哪个组件点亮，字幕跟真实断句。
   TTS 先别动（火山已接，缺 Key），先支持导入配音完成闭环。
```
