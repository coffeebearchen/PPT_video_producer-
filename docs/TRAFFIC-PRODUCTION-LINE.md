# 引流版生产线

## 1. 它是什么

不是单纯文案，也不是一个页面模板。

它由三层组成：

```text
叙事结构
字段模板
生产流程
```

### 叙事结构

```text
2 秒钩子
一个具体代价
一个类比
一句判断
一个下一条
一个动作
```

### 字段模板

```json
{
  "series": "AI 黑话避坑",
  "index": 1,
  "term": "Token 计费",
  "hook": "同一句话，中文问 AI 更贵",
  "cost": "你以为按字数，其实按 token 切块",
  "analogy": "像打车按里程，不像按字数",
  "proof": ["中文 1 字约 1–2 token", "英文 1 词约 1–2 token", "同样意思，token 数不同"],
  "judgment": "贵不贵，看切块",
  "next": "为什么 AI 会一本正经胡说",
  "cta": "有问题，评论区问",
  "page_count": 4,
  "palette": "archive"
}
```

### 生产流程

```text
选题 → 生成字段 → 校验 → 渲染 → 审片 → 发布 → 复用
```

---

## 2. 页面映射

### 4 页紧凑版

```text
P1 封面：hook
P2 背景：cost 场景
P3 对照：analogy / 反差
P4 金句：judgment + next + CTA
```

适合：

```text
20 秒
短视频
冷启动测试
```

### 5 页完整版

```text
P1 封面：hook
P2 背景：cost 场景
P3 对照：analogy
P4 证据：proof 三点
P5 金句：judgment + next + CTA
```

适合：

```text
24 秒
系列化
建立可信度
```

---

## 3. 校验规则

```text
hook <= 22 字
必须有代价
必须有一个类比
必须有三点证据（5 页版）
next 必须指向下一条
只允许一个 CTA
不出现结构词
不出现页码
```

---

## 4. 选题规则

优先：

```text
钱
被骗
面子
工作返工
```

不要：

```text
注意力机制
位置编码
纯定义
```
