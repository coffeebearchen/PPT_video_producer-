# 固定地址 · 内容工作台

## 一句话

把一条选题，做成可审批、可批量、可复用的竖屏内容资产。

---

## 100 字介绍

固定地址 · 内容工作台，是一套本地运行的自媒体内容生产系统。它把选题、资料、结构、文案、竖屏视频、审批、发布包串成一条流水线：一条选题可以生成 4/5/6 页脚本，自动渲染 1080×1920 成片，经过预览和审批后进入发布队列。适合个人品牌、知识博主和小团队，把重复生产变成稳定产能。

---

## 它解决什么问题

做一条知识类竖屏视频，通常会卡在五件事：

```text
选题散
资料找不到
文案每次重写
排版和动画每次重调
成片、封面、发布包分散
```

内容工作台把这些收进一个本地工作区：

```text
一个选题
一份结构
一套文案
一个视频规格
一条可回滚的成片
```

不是“一键爆款”，而是把内容生产变成可重复的系统。

---

## 核心流程

```text
选题 Brief
  ↓
资料源 / 知识库 / 结构库 / 灵魂档案
  ↓
角度卡
  ↓
页面文案
  ↓
视频 Spec
  ↓
预览帧
  ↓
完整成片
  ↓
审批
  ↓
发布包 / 公众号图文
  ↓
素材库归档
```

每一步都有记录，成片可以回到对应的 Spec 和版本。

---

## 主要功能

### 1. 选题与资料

```text
新建 Brief：话题、受众、结构、数量、禁区、渠道、CTA
URL 抓取标题和正文
知识库扫描 Markdown / TXT
按段落切块、关键词检索、引用回看
```

### 2. 内容资产

```text
知识库：文章、脚本、笔记
结构库：源域 → 目标域的类比映射
灵魂档案：信念、禁用表达、语感、签名、黄金样例
素材库：成片、封面、预览、版本、hash
音乐库：上传、分类、BPM、试听、选曲建议
模板库 / 元素库：视觉组件与矢量元素
```

### 3. 文案生成

```text
角度卡：1–6 个可选角度
页面文案：封面、背景、对照、证据、金句
字段级编辑：改一句，不重生成整条
Lite 模式：一条内容一次模型调用
缓存：相同 brief 命中缓存，不重复消耗
```

### 4. 竖屏视频

```text
1080 × 1920
30fps
H.264
4 / 5 / 6 页
中间 80% 安全区
正文不低于 24px
固定字段与层级
```

### 5. 视觉系统

```text
纸本 / 终端 / 编辑红 / 黑黄 / 大地绿
B1 / B2 / B3 系列色
旧背景、旧矢量元素、旧运动
半速元素运动
文字进入
高亮刷色
X / ✓
最后一页“有问题，评论区问”
```

### 6. 预览与质量闸门

```text
3 帧预览
排版越界检查
字号检查
结构词检查
断行检查
渲染前预览
```

### 7. 审批与发布

```text
播放器 + 页面预览 + 来源
5 项审批清单
批注、通过、退回
视频号发布包：MP4 + 封面 + metadata + README
公众号图文：标题、摘要、开头、3 节、来源、CTA
dry-run
发布状态回填
```

### 8. 批量生产

```text
批量选题
批量渲染
队列串行执行
失败重试
断点续跑
ZIP 导出
```

### 9. 版本与回滚

```text
Spec 版本
渲染 hash
发布包
冻结版本
旧版本保留
本地数据库备份
```

## 适合谁

```text
个人品牌
知识博主
AI / 科技内容账号
一人公司
2–5 人内容小团队
需要稳定产能、但不想把内容交给黑盒工具的人
```

---

## 不适合谁

```text
想要一键生成爆款、不做审稿的人
需要复杂真人拍摄、剪辑、特效的人
需要多人实时协作的大团队
完全不想维护本地环境的人
```

---

## 它不是

```text
不是通用视频编辑器
不是自动涨粉机器
不是无脑搬运工具
不是替代创作者判断的 AI
```

它是：

```text
一个把创作者的判断、结构和风格，固化成生产线的本地工作台。
```

## 30 秒介绍口播

> 这是一套本地运行的内容工作台。  
> 你把选题、资料和结构放进去，它帮你生成 4 到 6 页竖屏脚本，渲染成 1080×1920 的视频，再经过预览、审批，最后输出视频号和公众号的发布包。  
> 它不追求一键爆款，追求的是：每一条内容都有结构、有版本、能回滚、能批量。
