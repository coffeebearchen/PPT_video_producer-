## A. 插画偏好与模型选择

记录时间：2026-11-05

### 喜欢的方向

```text
编辑插画
扁平矢量
粗黑描边
大色块
奶油纸底
红 / 黑 / 荧光绿点缀
轻微网点或纸张颗粒
一个画面只讲一个隐喻
一个人物或一个主物体
留白多
不写文字
```

参考风格：TED 演讲精读类封面插画，但不要照抄。

### 不喜欢

```text
元素堆砌
多个主角
信息图拼盘
没有唯一动作
复杂背景
和文字抢注意力
```

### 一条视频的规则

```text
至少 1 张主插画
最多 2 张
只放背景页或证据页
不放封面
颜色跟随模板
```

## B. 内容与引流参考（WorkBuddy 复盘）

### 结论

```text
视频目的：引流，不是词条科普
形式不是壁垒
人格、系列资产、承接、去处才是
```

### 要借鉴

```text
1. 不讲“这个词是什么”，讲“这个词关我什么事”
2. 只选跟钱、骗、面子、工作有关的题
3. 固定人格与固定立场
4. 一条内容只服务一个动作
5. 前 2 秒给钩子
6. 结尾留下一条的扣子
7. 做成系列资产，不做单条爆款
8. 视频负责引流，公众号负责承接
9. 一条内容复用五种形态
10. 用损失感替代定义
```

### 要避免

```text
100 条薄词条
只有信息没有观点
每条都换人设
一条视频同时要求关注、点赞、进群、领资料
把公众号当短视频搬运地
只追动画形式
```

### 我们的优势

```text
模板化产能
视觉完成度
4 / 5 / 6 页结构
旧背景 / 旧元素 / 运动系统
可批量生产
```

### 我们的短板

```text
人格不固定
选题偏“纠错”，不够“关我什么事”
没有系列资产
没有明确承接
结尾 CTA 偏弱
缺少评论区关键词
```

### 立刻可做

```text
1. 10 条标题改成“代价 / 风险 / 钱 / 工作”角度
2. 固定一句人格声明
3. 每条最后加“下一条讲……”
4. 做一期“AI 黑话 30 期”系列封面
5. 公众号做承接页
6. 评论区设一个关键词
```

### 内容骨架

```text
0–2s   反常识钩子
2–8s   一个具体代价
8–18s  一个类比
18–24s 一句判断
最后   下一条扣子 + 一个动作
```
