# 文字动效导演手册（Text Motion Manual）v1

> 给「AI 编导」和「渲染器」共用：AI 照着选，渲染器照着放，人照着改。
> 文字动效是最容易「乱加」的地方——逐字抖、循环呼吸、和图形抢戏。这份手册定死规则。

## 0. 总纲

```text
1. 文字动效服务「读」，不服务「炫」。
2. 一页只有一次主强调，文字的动不能和图形的动抢。
3. 动完必须停在干净静帧，不循环、不抖动。
4. 文字先可读，再谈动。
```

## 1. 文字角色（7 种）

| 角色 | 出现在 | 作用 |
|---|---|---|
| **主标题** | title 页 | 抓人，一句定调 |
| **副标题** | title 页 | 补充一句 |
| **正文/说明** | 各页 | 解释内容 |
| **要点条目** | bullet 页 | 一条一条讲 |
| **金句** | quote 页 | 收尾金句 |
| **标注** | 截图/图解页 | 局部提示 |
| **字幕** | 全页 | 跟旁白 |

## 2. 每个角色的默认动效

| 角色 | 动效 | 参数 | 为什么不选别的 |
|---|---|---|---|
| **主标题** | `reveal.typewriter`（by:"line"）| 400ms | 逐行打出，有节奏，不逐字抖 |
| **副标题** | `reveal.fade` | 400ms | 跟标题，不抢 |
| **正文** | `reveal.fade` | 300ms | 要快，别让观众等 |
| **要点条目** | `reveal.stagger` | 每项 400ms，间隔 200ms | 一条一条，有数 |
| **金句** | `reveal.fade` + `texture.lightSweep` | 400ms + 600ms | 收尾要「静」，光扫一次 |
| **标注** | `annotationAnim.draw` | 400–600ms | 画出来，不闪 |
| **字幕** | 无（跟旁白直接出）| — | 字幕动会晕 |

## 3. 时序（页内）

```text
0–10%   转场（进页）
10–25%  文字进入（标题 400ms）
25–70%  文字停留 + 图形动
70–100% 静帧留白（让人读）
末帧     干净静帧
```

**硬规则**：
```text
- 文字进入 ≤ 600ms（慢了像卡住）
- 文字停稳后 ≥ 1000ms 才切页（让人读完）
- 文字退场不单独做（跟整页转场走）
```

## 4. 文字和旁白的同步

```text
1. 旁白念到哪，字幕到哪（cues 已有）。
2. 旁白念到某个词，屏幕上「对应文字」高亮（textSync）。
3. textSync 的荧光刷：从左到右刷过（0.4–0.8s），停在文字上。
4. 一页只刷一次重点。
```

**实现状态**：
```text
✅ cues 字幕同步（已实现）
✅ annotationAnim.draw 画线（已实现）
❌ textSync 荧光刷（未实现，待 Codex）
```

## 5. 禁止清单

```text
- 不逐字抖动（typewriter 是「出现」，不是「抖」）
- 不循环呼吸（pulse 最多 2 次）
- 文字不和图形同时动（一个先动，一个后动）
- 不用字幕做「强调」（字幕是读的，不是炫的）
- 一页最多一个文字动效（标题动了，正文就静）
- 字号不为动效牺牲（正文 ≥24，说明 ≥28）
```

## 6. 决策表（文字角色 × 意图 → 动效）

| 场景 | 动效 |
|---|---|
| 开场定调 | 主标题 typewriter（line）|
| 补充说明 | 副标题 fade |
| 讲要点 | 条目 stagger |
| 讲流程 | 节点标签 stagger |
| 收尾 | 金句 fade + lightSweep |
| 指位置 | 标注 draw |
| 划重点 | textSync 荧光刷（待实现）|

## 7. 实现边界（渲染器真实能力）

| 效果 | 已实现 | 说明 |
|---|---|---|
| `reveal.typewriter`（char/line）| ✅ | `AnimatedCopy` |
| `reveal.fade` | ✅ | opacity |
