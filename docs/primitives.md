# 页面原语 v1.0

| id | 名称 | 页面 | 槽位 |
|---|---|---|---|
| single-column | 单柱大字 | P1 | headline / highlight |
| compare-vertical | 上下对照 | P2 | left / right / conclusion |
| compare-horizontal | 左右对照 | P2 | left / right / conclusion |
| compare-diagonal | 对角对照 | P2 | left / right / conclusion |
| causal-chain | 因果链 | P3 | cause / mechanism / result |
| checklist | 清单 | P3 | items |
| boundary | 边界 | P3 | fit / not-fit |
| quote | 金句 | P4 | line1 / line2 / highlight |

运行时通过 `data-primitive` 标记；P2 根据文案长度自动选择，Editorial 固定上下。
