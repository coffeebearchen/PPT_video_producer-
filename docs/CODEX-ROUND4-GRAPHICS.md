# 给 Codex 的指令：图形 / 形状 / 图表 / 装饰 扩充

> 先读 D:\AI数字资产\studio\docs\STYLE-REGISTRY.md 和 CODEX-ROUND3-INDUSTRIAL.md。
> 本轮目标是：让讲解画面的“图形类型 + 形状 + 图表 + 装饰”明显变多、变活。

---

## 一、要扩充的四大类

### 1. 流程分析类

```text
流程 / 泳道 / 因果链 / 循环 / 分支 / 树
矩阵 / 金字塔 / 中心辐射 / 层级 / 漏斗
```

### 2. 几何形状

```text
三角形、圆、方形、菱形、六边形、多边形
箭头、括号、齿轮、星形、旗帜、标签角
```

### 3. 统计图形（在现有 7 种图之外再补）

```text
现有：line / step / bar / hbar / area / pie / donut
补充：radar 雷达 / scatter 散点 / gauge 仪表 /
      funnel 漏斗 / heatmap 热力 / progress ring 进度环
```

### 4. 流动矢量小图 + 装饰图案

```text
流动线条 / 轨迹 / 粒子流 / 光束 / 波纹
点阵 / 斜纹 / 几何纹样 / 角标
常用图标：人 / 钱 / 时间 / 警告 / 对勾 / 时钟 / 齿轮
```

---

## 二、要求

```text
1. 全部用代码画（React + SVG + Rough.js），不许 AI 生图
2. 每个图形/图表/装饰是可复用的组件，按 props 控制
3. 动效要“流动、有节奏”，但克制，不杂乱
4. 图表必须支持：柱状生长 / 曲线逐步绘制 / 数值滚动 / 当前项高亮
5. 装饰小图案要小、淡、可开关，不抢主内容
6. 内容在中间 80% 安全区
```

---

## 三、验收

```text
1. 每个新图形/图表/装饰，渲一张静态预览 PNG，
   拼成“图形扩充画廊”给我看

2. 再用一段文案做一条 20–30 秒样片，
   这条片要明显用上：不同形状 + 统计图 + 流动线 + 装饰小图

3. 抽 8–10 帧 contact-sheet.png 给我看
```

---

## 四、交付（中文）

```text
1. 新增哪些组件、图表、装饰，各是什么
2. 如何用 props 控制
3. 预览画廊 + 样片的本地路径
4. 测试结果 + 未验证项
```
