# 固定地址 · 内容工作台 v1.0 使用说明

## 启动

```powershell
cd D:\AI数字资产\studio
node server.mjs
```

打开：

```text
http://127.0.0.1:4310
```

## 标准生产流程

```text
1. 创作台：新建 Brief
2. 选题：生成角度、选结构
3. 文案：生成 4/5/6 页文案 + 金句
4. 结构库：检查结构字段
5. 预览：低清预览帧
6. 审批：检查预检、审批 / 退回
7. 批量生产：选择多条文案，进入队列
8. 下载：批次目录 / ZIP
```

## 批量生产

```text
批量新建：标题 | 话题 | 结构类型 | 主题 | 页数
开始批量渲染：进入全局队列
批量预览：生成 5 帧，可点开大图
重新渲染：用当前模板覆盖旧 MP4
批量通过 / 退回：审批
取消 / 删除 / 重试：队列控制
```

输出目录：

```text
data/batch-output/<批次ID>/
```

## 失败处理

```text
正在渲染中：已有批次占用，队列会依次执行
布局闸门：layout issue > 0 时不交付
超时 / 中断：重启服务，自动恢复 queued/running 批次
```

## 备份与恢复

```powershell
node scripts/backup.mjs
node scripts/restore.mjs backups/<目录> --yes
```

恢复前必须停止服务。
