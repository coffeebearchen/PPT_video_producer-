## 01 · Token 计费

### 0–2 秒钩子

```text
同一句话，中文问 AI 比英文更贵。
```

### 标题

```text
同一句话，中文问 AI 更贵
不是错觉，是按 token 收费
```

### 背景页

```text
场景：你每天用中文让 AI 改文案
角色：中文被切成更多 token，英文单词更少
限制：不是按字数，是按 token 计费
```

### 对照页

```text
看起来是：按字数 / 最公平
其实是：按 token / 切块收费
结论：贵不贵，看切块
```

### 证据页

```text
中文 1 个字 ≈ 1–2 token
英文 1 个词 ≈ 1–2 token
同样意思，token 数不同
```

高亮：

```text
同样意思，token 数不同
```

### 结尾

```text
AI 不是按字收费
是按切块收费
```

注释：

```text
下一次，先问 token 单价。
下一条：为什么 AI 会一本正经胡说。
```

## 02 · AI 幻觉

### 0–2 秒钩子

```text
AI 最危险的时候，不是不会，是它不会也说会。
```

### 标题

```text
AI 不是骗你
它在补空
```

### 背景页

```text
场景：你让 AI 查一个不存在的文件
角色：它会编一个像真的答案
限制：没有来源，还说得很快
```

### 对照页

```text
看起来是：不知道 / 应该停下
其实是：编一个 / 看起来更专业
结论：流畅不等于真实
```

### 证据页

```text
没有引用，先别信
细节越具体，越要查
先让它给来源
```

高亮：

```text
先让它给来源
```

### 结尾

```text
AI 不是骗你
它是在补空
```

注释：

```text
先查来源，再信结论。
下一条：为什么 AI 刚聊完就忘。
```

## 03 · 上下文遗忘

### 0–2 秒钩子

```text
AI 刚聊完就忘，不是它笨，是你把窗口当硬盘。
```

### 标题

```text
AI 刚聊完就忘
不是它记性差
```

### 背景页

```text
场景：你让它记住三天前的需求
角色：它只看到当前窗口
限制：窗口是处理范围，不是长期记忆
```

### 对照页

```text
看起来是：聊天记录 / 以为它都记得
其实是：上下文窗口 / 只装当前这一段
结论：不是记忆，是工作台
```

### 证据页

```text
窗口满了会截断
重要信息要外置
文档和数据库才是记忆
```

高亮：

```text
窗口满了会截断
```

### 结尾

```text
窗口不是记忆
是处理范围
```

注释：

```text
把重要的事，放到窗口外。
下一条：RAG 到底在补什么。
```
