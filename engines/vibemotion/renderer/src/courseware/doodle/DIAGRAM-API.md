# Diagram 页调用与 45 种 data 结构

绘制源：scripts/gen-handdrawn-samples.mjs @ 2fe3858。原 L.XXX 几何函数保留在 source.js。

```json
{
  "id": "d",
  "kind": "diagram",
  "layout": "B03",
  "title": "循环",
  "data": {
    "nodes": [
      "计划",
      "执行",
      "检查",
      "调整"
    ]
  },
  "fromFrame": 0,
  "durationInFrames": 180
}
```

支持 title 别名，冻结后的 text 为标题；caption 作为图下说明。fromFrame/durationInFrames 为 30fps 冻结时间。使用 Courseware 入口即可，出现 diagram 时启用独立涂鸦渲染路径。旧 dynamicflow 目录与两份 style 文件保持不变。

## 数据约定

以下 JSON 是每种布局完整 data 示例，字段均必填。数组是原脚本的固定绘制槽位，长度与示例一致；需要其他节点容量时另做布局适配，不能静默截断。C08 例外：total 1–600，activeIndices 可变且不得重复或越界。

C01/C02/C04/C06/C09/C10 的 values/series 为 0–1 归一化值；C03 的 points 为原绘图坐标；C05 范围 0–100；C07 value 为占比且合计 1；D01 counts 为 1–30 的整数。数值改变会改变图形几何或状态，不只是文字。A08 漏斗宽度为示意，count 为显示数值。

## 样片与运行

样片入口 demo.tsx，8 页 × 6 秒 = 48 秒，1080×1920 / 30fps，无配音无 BGM（视觉演示）。

```sh
node src/courseware/doodle/check.mjs
npx remotion render src/courseware/doodle/demo.tsx SuperAgentDoodle ../../../out/super-agent-doodle/demo.mp4 --concurrency=2
```

## 适配说明

仅做组件化、数据绑定、语义色归一和安全区适配。色板遵循 docs/DIRECTOR-MANUAL.md 2.1.1；区域使用 hatch（-41°，默认间距 8px，D01 为 9px），文字块和线条框不加斜线；全页暗角中心透明、外沿 28% 黑；保留脚本 grain、文字位移 1.1 与粉笔线条位移 3.2。roughjs 基准 roughness 2.2 / bowing 1.6 / 固定种子；保留原函数中对特殊数据图笔画的局部设定。C08 修正为实际 300 点/20 亮点；B05 扩成三泳道。标题换为内容标题，不显示 A02 等内部编号。黑体栈雅黑/苹方/Noto Sans CJK SC；Linux 实际使用 Noto Sans CJK SC。

动画完全由 frame/fps 推导：strokeDashoffset 逐笔、节点文字从 0.91 缩放至 1（无往复弹跳）、网格先逐点出现再逐点点亮。约 3.5 秒完成，余下时间静止阅读。
